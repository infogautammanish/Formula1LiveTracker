# Formula1LiveTracker
🏎️ Interactive Formula 1 Data Analysis Dashboard built with Python, Pandas, NumPy, Matplotlib and Streamlit. Analyze driver performance, constructor standings, race results, reliability, points distribution and track performance across F1 seasons 2024-2026.

# 🏎️ Formula 1 Live Tracker

An interactive **Formula 1 Data Analytics Dashboard** built with Python and Streamlit. Explore driver performance, constructor standings, race results, reliability, points distribution, and circuit performance through an easy-to-use interactive dashboard.

## 🚀 Live Demo

👉 **[Launch Formula 1 Live Tracker](https://formula1livetracker.streamlit.app/)**

Try the live dashboard directly in your browser without installing anything.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/infogautammanish/Formula1LiveTracker.git
```

### 2. Open the project folder

```bash
cd Formula1LiveTracker
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit dashboard

```bash
streamlit run f1_dashboard.py
```

The application will normally be available at:

```text
http://localhost:8501
```
